# Privacy Policy — Unraid Backup

**Last updated:** October 10, 2026

## Overview

Unraid Backup is a private, non-commercial application used exclusively for personal backups to Google Drive.

## Data Access

The application accesses Google Drive only to upload, retrieve, verify, and manage backup files.

## Data Security

- Files are encrypted locally using Restic before being uploaded.
- Google account passwords are not collected or stored by the application.
- OAuth credentials are stored locally on the user's server.
- Backup data is not shared with third parties.

## Data Storage and Retention

Encrypted backups are stored in the user's own Google Drive account. Backup retention is managed locally using Restic.

## Data Sharing

No personal data is sold or shared with advertisers or other users.

## Revoking Access

Users can revoke the application's Google Drive access through their Google Account security settings and delete stored backups directly from Google Drive.

## Contact

This application is intended for personal use only. Privacy inquiries can be submitted through the project's public GitHub repository.
