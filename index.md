# Unraid Backup

Unraid Backup is a personal, non-commercial backup application used to securely store encrypted backups on Google Drive.

The application uses rclone to transfer backup data and Restic to encrypt files locally before uploading them.

Google Drive access is used exclusively for storing and retrieving personal backups.

This application is not offered as a public service.

For information about data handling, see our [Privacy Policy](privacy.md).
